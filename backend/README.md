# GangOfThree - Backend (API) 🚀

This is the core backend service for the **GangOfThree** project, built with **Spring Boot 3** and **Java 21**. It handles authentication, ticket management, and advanced search capabilities using a modern tech stack.

## 🛠 Tech Stack

*   **Runtime:** Java 21 (Eclipse Temurin)
*   **Framework:** Spring Boot 3.x
*   **Build Tool:** Gradle
*   **Database:** PostgreSQL 18
*   **Caching:** Redis 7
*   **Search Engine:** Elasticsearch 8.15.3 (with Kibana)
*   **Security:** Spring Security & JWT
*   **Containerization:** Docker & Docker Compose
